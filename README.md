# GamePad Tester Offline

Офлайн-приложение для Windows и macOS: тест и калибровка контроллеров PlayStation
(DualShock 4, DualSense, DualSense Edge, PS VR2) — те же функции, что на сайте
[dualshock-tools.github.io](https://dualshock-tools.github.io/), но без интернета.

Внутри — Electron, который запускает **оригинальный интерфейс и логику сайта**
(проект dualshock-tools, лицензия MIT). Мы не переписываем протокол калибровки,
а собираем исходники сайта на закреплённом коммите и применяем небольшие патчи
для офлайн-режима.

## Что умеет

Всё, что умеет сайт: калибровка центров стиков (быстрая и в 4 шага), калибровка
диапазона, тонкая настройка (DualSense), быстрые тесты (кнопки, гироскоп/IMU,
тачпад, вибрация, подсветка, микрофон, динамик, наушники, адаптивные триггеры,
USB), информация о прошивке и железе, NVS, перезагрузка контроллера, история
калибровок, 24 языка (английский + 23 перевода; язык выбирается по системному
автоматически, а также вручную в меню).

## Приватность

Приложение **не выходит в сеть**:

- Bootstrap, jQuery и Font Awesome лежат внутри приложения (`web/vendor/`), а не грузятся с CDN.
- Вырезаны Google Tag Manager и собственная аналитика сайта (`the.al/ds4_a/l`),
  которая отправляла сырые HID-данные и Bluetooth-адрес контроллера.
- Любой запрос `http(s)/ws/ftp` из окна блокируется на уровне Electron
  (`onBeforeRequest`), а CSP страницы разрешает только свой origin.
- Ссылки из окон справки (PayPal, GitHub, YouTube) открываются в системном браузере, только когда вы по ним нажмёте.

Нижняя планка сайта (версия, ссылка на пожертвования, значки соцсетей, имена переводчиков)
убрана. Авторы и лицензия доступны в меню **Справка → О программе и авторах**
(в macOS — в меню приложения), полный текст лицензии — в `THIRD_PARTY_NOTICES.md`.

## Использование

1. Установите приложение (см. «Установка»).
2. Подключите контроллер **USB-кабелем** (по Bluetooth калибровка не работает).
3. Нажмите **Подключить**. Если найден один контроллер, он выбирается сам;
   если несколько — появится диалог выбора.

> ⚠️ Калибровка меняет данные во флеш-памяти контроллера. Держите контроллер
> заряженным, не отключайте кабель во время операций, сначала пробуйте
> временную калибровку. Инструмент **не лечит дрейф стиков** — при износе
> механики стик нужно менять. Используйте на свой риск.

## Установка

Готовые сборки — на странице релизов репозитория (собираются в GitHub Actions).

| ОС | Файл |
|---|---|
| Windows | `GamePad Tester Offline-Setup-<версия>-x64.exe` (установщик) или `...-Portable-...exe` |
| macOS | `GamePad Tester Offline-<версия>-mac-arm64.dmg` (Apple Silicon) / `...-mac-x64.dmg` (Intel) |

Сборки **не подписаны** сертификатами разработчика:

- **Windows:** SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».
- **macOS:** приложение подписано ad-hoc. При первом запуске macOS может сказать,
  что оно от неопознанного разработчика: *Системные настройки → Конфиденциальность
  и безопасность → «Всё равно открыть»* (на более старых macOS — правый клик → «Открыть»).
  При первом тесте микрофона система спросит доступ к микрофону.

Чтобы убрать эти предупреждения, нужны платный Apple Developer ID (плюс
нотаризация) и сертификат подписи кода для Windows. electron-builder подхватит их
через переменные окружения `CSC_LINK` / `CSC_KEY_PASSWORD`.

## Разработка

Нужны Node.js 20+ и Git.

```bash
npm ci
npm run build:web    # скачать сайт на закреплённом коммите, пропатчить, собрать в web/
npm start            # запустить приложение
npm run smoke        # автотест: страница, ресурсы, RTL, перевод, цепочка HID, 0 сетевых запросов
npm run dist:win     # установщик + portable для Windows  -> release/
npm run dist:mac     # dmg + zip (x64 и arm64), только на macOS -> release/
```

Собрать `.dmg` можно только на macOS. Из Windows это делает GitHub Actions
(`.github/workflows/build.yml`): при пуше тега `v*` собираются оба набора
установщиков и прикрепляются к релизу.

```bash
git tag v1.0.0
git push origin v1.0.0
```

### Как устроено

| Путь | Назначение |
|---|---|
| `scripts/upstream.json` | репозиторий и **закреплённый коммит** сайта |
| `scripts/patches.mjs` | офлайн-патчи; у каждого указано, сколько совпадений ожидается |
| `scripts/build-web.mjs` | fetch → патчи → штатная сборка сайта (gulp/rollup) → `web/` → проверка на сетевые ссылки |
| `electron/main.js` | окно, протокол `app://`, блокировка сети, права, выбор HID-устройства, меню |
| `electron/smoke-test.js` | самопроверка (`--smoke-test=<папка>`), делает скриншоты |
| `build/` | иконка, entitlements для macOS, ad-hoc подпись |

Почему свой протокол `app://ds/`: страница должна быть в *безопасном контексте*
(иначе нет `navigator.hid`), а `fetch`/XHR не работают с `file://`.

### Обновление до новой версии сайта

1. В `scripts/upstream.json` поставьте новый коммит. Для пробной сборки без правки файла
   задайте переменную окружения `UPSTREAM_REF` (например, `main`).
2. `npm run build:web`. Если сайт изменился так, что патч не находит свой фрагмент,
   сборка **упадёт с понятным сообщением** — поправьте `scripts/patches.mjs`, а не
   получите молча «дырявую» сборку.
3. `npm run smoke`, затем релиз.

Версия Bootstrap/jQuery/Font Awesome в `package.json` закреплена так же, как на сайте;
при их обновлении на сайте обновите и её.

## Известные ограничения

- HID-часть (открытие контроллера, калибровка) построена на том же WebHID в Chromium,
  что и сайт, но автотесты не используют реальный контроллер: проверяется всё до
  момента открытия устройства. Первый запуск с настоящим контроллером на каждой
  ОС стоит сделать вручную.
- Сборки для macOS собираются только в CI и здесь не запускались.
- Размер установщика ~105 МБ (внутри Chromium).
